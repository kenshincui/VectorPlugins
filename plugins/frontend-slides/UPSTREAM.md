# Upstream provenance and Vector adaptation

- Repository: https://github.com/zarazhangrui/frontend-slides
- Reference revision: `9906a34d640d2111f724544cbc50f7f130569ae1`
- Base release line: `v2.0.0`
- Imported path: repository root skill files and `scripts/`
- License: MIT

This package imports the user's Codex-adapted copy of Frontend Slides. Its
supporting files derive from upstream revisions in the v2.0.0 history, while
`SKILL.md` is adapted for Codex/Vector discovery, tool-neutral asset inspection,
HTML enhancement, sharing, and export.

The adapted package intentionally retains the responsive full-viewport slide
model from the imported copy. Current upstream `main` instead uses a fixed
1920x1080 16:9 stage and includes an optional bold template pack; those newer
behaviors and assets are not silently substituted into this Vector package.
