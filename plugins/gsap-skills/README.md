# GSAP Skills

GreenSock 官方 8 项 Agent Skills 的 Vector 社区插件包。

| Skill | 能力 |
| --- | --- |
| gsap-core | 核心 API、缓动、错峰动画、响应式与减少动态效果 |
| gsap-timeline | 时间线、标签、嵌套与播放控制 |
| gsap-scrolltrigger | 滚动驱动动画、固定、刷新与清理 |
| gsap-plugins | Flip、Draggable、SplitText、SVG 等插件 |
| gsap-utils | 数值映射、选择器、插值等工具函数 |
| gsap-react | useGSAP、作用域、SSR 与卸载清理 |
| gsap-frameworks | Vue、Nuxt、Svelte 等框架生命周期集成 |
| gsap-performance | 动画性能与布局开销优化 |

在 VectorDesktop 的社区插件目录刷新后，找到 **GSAP Skills** 并安装、启用。
安装本插件只提供技能文档，不会自动安装项目依赖或执行脚本。实际编写动画时，
按项目需要安装 `gsap`；React 集成可使用 `@gsap/react`。
