# Minimalist UI

来自 [Taste Skill](https://github.com/Leonxlnx/taste-skill) 的 `minimalist-ui` 技能。

- 暖白背景、单色主调与低饱和点缀。
- 精细排版、充分留白与扁平网格。
- 组件细节、图标和克制的微动效。

在 VectorDesktop 社区插件目录刷新后，找到 **Minimalist UI** 并安装、启用。
仅提供设计技能文档，不会自动安装依赖或修改项目。该技能是编辑式极简设计方向，
并非 Apple 官方规范；应用到已有产品时仍应遵循项目自己的主题与组件约定。
